PLASTICPANIC

Figurines en plastique, gadgets farfelus et chaos physique — 2 à 8 joueurs.

Commandes
PC
ZQSD / WASD : déplacement
Souris : visée — Clic gauche : tir
Clic droit ou E : gadget
Espace : esquive (recharge 4 s)
1 2 3 : choisir l'arme / déclencher un gadget
R / F : consommables — B : boutique
Tab : classement — M : son
Mobile (paysage)
Pouce gauche : déplacement
Pouce droit : visée (pousser à fond = tir)
Boutons : tir, esquive, gadget, consommables
Touchez un emplacement pour changer d'arme

Réglages

Commandes
Clavier / souris
ZQSD ou WASD, souris, clic : tir
Clic droit ou E : gadget
Espace ou Maj : esquive
Molette ou 1 2 3 : armes
R / F : consommables
B : boutique — Tab : scores
Manette
Stick gauche : bouger
Stick droit : viser (tir auto)
Gâchettes : tir
A : esquive — B : gadget
X / Y : consommables
LB / RB : armes — Start : boutique
